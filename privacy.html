一、隐私政策总则

1. 为保障用户个人隐私安全，规范个人信息处理行为，我们依据《中华人民共和国个人信息保护法》 《中华人民共和国网络安全法》等相关法律法规，并结合 PhotoColours 的产品功能，制定本隐私政策。

2. 本隐私政策适用于您使用 PhotoColours 及相关服务的全过程，包括但不限于照片选择、颜色提取、 实况卡片生成、图片或实况照片导出、广告展示等功能场景。

3. 您通过访问、下载、安装或使用 PhotoColours，即视为您已阅读、理解并同意本隐私政策；若您不同意， 请立即停止使用本应用及相关服务。

4. 我们有权根据法律法规变化、产品功能调整或运营需要对本政策进行更新。更新后的政策将通过应用内页面、 弹窗、公告或其他合理方式向您说明。您继续使用本应用，即视为接受更新后的政策。

二、我们收集和使用的信息

我们遵循合法、正当、必要、诚信原则，仅在实现产品功能或符合法律法规要求的范围内处理您的信息。

信息类型 使用场景 处理目的

照片元数据（如拍摄时间、拍摄地点） 您选择的照片本身包含这些元数据时 用于在实况卡片页面自动展示拍摄时间和拍摄地点。我们不会主动获取您的实时定位

2.1 相册与导出相关权限

  • 读取相册权限：用于让您选择照片或实况照片，并读取您所选内容对应的图像数据与必要元数据。
  • 保存到相册权限：用于将您生成或导出的图片、实况卡片保存到系统相册。

2.2 广告与跟踪说明

PhotoColours 集成了第三方广告服务，以支持部分运营能力。在相关广告场景下，第三方 SDK 可能会处理设备标识符、 网络信息、广告交互数据等，用于广告展示、监测、反作弊和效果归因。若系统要求，我们会先向您申请相应授权。

2.3 我们不会做的事情

  • 不会在未经您授权的情况下读取您未主动选择的照片内容。
  • 不会主动获取您的实时地理位置；拍摄地点仅来自您所选照片本身携带的元数据。
  • 不会在无必要情况下收集您的姓名、身份证号、银行卡号、通讯录等信息。

三、第三方 SDK 与服务说明

为实现广告展示、性能支持或系统能力接入，PhotoColours 可能接入第三方 SDK、系统框架或服务。我们会要求相关合作方在法律法规允许范围内处理信息，并采取必要的保护措施。

当前应用包含广告相关能力。第三方广告 SDK 可能基于其自身隐私政策处理部分设备信息、广告标识信息与交互数据。 您应同时关注第三方服务方对信息处理的说明。

四、个人信息的存储与保护

1. 我们会采取合理可行的安全措施保护您的信息，包括但不限于访问控制、传输加密、最小权限、日志审计等。

2. 我们仅在实现本政策所述目的所必需的最短期限内保存相关信息；达到保存期限后，我们会按照法律法规要求删除或做匿名化处理。

3. 除法律法规另有规定外，我们原则上在中华人民共和国境内存储所收集的信息。

4. 尽管我们已采取合理措施，但互联网并非绝对安全环境，请您妥善保管自己的设备及账号环境，并及时更新系统与安全软件。

五、您的权利

在法律法规规定范围内，您通常享有以下权利：

  1. 查阅权：您有权了解我们处理您个人信息的情况。
  2. 更正权：若您发现我们处理的信息存在错误，您有权要求更正。
  3. 删除权：在符合法律规定条件时，您可以要求删除您的相关个人信息。
  4. 撤回同意权：您可以通过系统权限设置等方式撤回授权，但撤回后部分功能可能无法正常使用。
  5. 投诉与反馈权：如您对隐私保护存在疑问、意见或投诉，可通过本政策底部联系方式与我们联系。

若您提出上述请求，我们将在核验您的身份后，于法律法规要求或合理期限内进行处理。

六、未成年人保护

若您是未成年人，建议您在监护人陪同下阅读本政策，并在取得监护人同意后使用相关服务。 若我们发现存在未依法取得监护人同意而处理未成年人个人信息的情形，将依法采取删除或停止处理等措施。
