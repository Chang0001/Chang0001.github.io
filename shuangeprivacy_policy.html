二、我们如何收集和使用信息

本游戏自身为休闲娱乐产品，通常不会主动要求您填写姓名、身份证号、通讯录、短信、通话记录等个人敏感信息。

为了提供小米渠道登录、实名认证、防沉迷、广告展示、广告归因、广告反作弊、问题排查和安全风控等能力，我们接入的第三方 SDK 可能会依法收集和处理必要信息。

  • 账号与登录信息：用于小米账号登录、账号状态识别、渠道服务。
  • 设备与应用信息：包括设备标识符、OAID、设备基础信息、应用信息、系统版本、应用安装或运行相关信息等，用于 SDK 初始化、广告展示、广告反作弊、安全风控和崩溃排查。
  • 网络信息：包括网络状态、WIFI 信息、设备 IP、网络连接信息等，用于登录、实名/防沉迷、广告请求、广告素材加载和基础网络诊断。
  • 广告交互信息：包括广告加载、展示、点击、关闭、跳过、观看完成、奖励回调等，用于广告计费、效果统计和反作弊。

四、权限使用说明

本游戏及接入的 SDK 可能会使用以下系统权限或能力，具体以实际安装包和系统授权提示为准：

  • 网络访问权限：用于小米登录、实名/防沉迷、广告请求、广告素材加载和问题排查。
  • 网络状态权限：用于判断网络连接状态，获取 WIFI 连接状态、SSID、设备 IP 等信息，优化登录、广告加载、广告反作弊和错误诊断。
  • 存储或文件访问相关能力：用于广告素材缓存、日志缓存或 SDK 必要文件访问。若系统需要单独授权，将以系统弹窗为准。
  • 安装应用相关权限：当前安装包中可能包含广告或渠道 SDK 声明的安装相关权限，实际使用以系统授权、SDK 能力和应用场景为准。
  • 设备基础信息访问：可能包括 OAID、设备标识符、系统属性、已安装 APP 信息或正在运行的应用信息，用于小米登录、实名/防沉迷、广告投放、安全风控、反作弊、渠道统计和兼容性适配。

我们不会通过本游戏主动读取您的通讯录、短信、通话记录、相册内容或精确位置信息，除非未来功能确有必要并依法另行告知和征得同意。

五、广告展示说明

本游戏可能通过广告实现变现。您在使用过程中可能看到以下广告形式：

  • 开屏广告：在启动游戏时展示。
  • Banner 广告：通常在主页或菜单页底部展示。
  • 插屏视频广告：可能在开始游戏、进入玩法页、返回主页或关卡流程节点展示。
  • 激励视频广告：可能在特定游戏场景中展示，并根据广告 SDK 返回的有效观看结果处理奖励或继续流程。

广告 SDK 可能基于设备、网络、广告交互等必要信息进行广告请求、展示、计费、归因和反作弊。
