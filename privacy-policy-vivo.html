2. 我们处理的本地图片信息

当你主动选择照片时，本应用会在设备本地处理与你所选照片相关的信息，包括照片像素内容、照片中可读取的拍摄时间、位置信息以及动态照片附带的本地元数据。这些处理用于完成颜色提取、背景色计算、卡片文案默认值生成、排版预览以及最终图片导出。除你主动导出或系统正常读写所必需的处理外，我们不会因为广告展示而上传你的原始照片、照片元数据或导出后的图片内容。

3. 接入的第三方 SDK：穿山甲广告 SDK

当前版本接入了穿山甲广告 SDK，由北京巨量引擎网络技术有限公司提供，主要用于广告展示、广告请求与填充、广告监测归因、广告投放统计分析、反作弊、广告落地页适配与稳定性保障。按照当前版本的实现，只有在你阅读并同意本隐私政策后，应用才会启动广告相关服务。根据穿山甲官方公示，开发者需在隐私政策中向用户明示 SDK 名称、主体名称、处理个人信息种类及目的、隐私政策等内容；具体处理字段和是否启用，可能因 SDK 版本、系统版本、设备型号和广告类型而存在差异，以实际接入版本为准。穿山甲 SDK 服务基本信息公示与隐私说明：https://www.csjplatform.com/privacy/partner 。穿山甲官方合规指南：https://www.csjplatform.com/terms/compliance-guide 。穿山甲 Android SDK 接入说明：https://www.csjplatform.com/supportcenter/5397 。

4. 穿山甲广告 SDK 可能处理的信息类型、字段、目的、方式与范围

根据穿山甲官方公示，穿山甲广告 SDK 在广告投放合作场景下可能处理以下信息。设备信息：设备品牌、型号、软件系统版本、屏幕密度、屏幕分辨率、设备语言、设备时区、SIM 卡信息（MCC&MNC）、CPU 信息、可用存储空间大小、OAID、Android ID；在部分 Android 设备和系统版本下，还可能包括设备 MAC 地址以及设备标识符（如 IMEI、IMSI、ICCID、GAID、MEID、硬件序列号等），用于广告投放、广告反作弊，其中 Android ID、OAID、设备 MAC 地址、设备型号等还可能用于广告监测归因。网络信息：运营商信息、Wi‑Fi 状态、网络信号强度、IP 地址，用于保证网络服务有效性及稳定性，并用于广告投放、广告监测归因和广告反作弊。应用信息：应用包名、版本号、应用前后台状态、运行中的进程信息；在可选场景下，还可能包括软件列表信息、已安装应用列表、应用包名列表，用于广告投放、广告反作弊、广告落地页唤起适配和归因分析。传感器信息：在可选广告样式下，可能包括加速度传感器、陀螺仪传感器、线性加速度传感器、磁场传感器、旋转矢量传感器信息以及传感器列表，用于摇一摇、扭一扭等广告投放、广告反作弊以及个性化广告推荐相关能力。广告信息：对广告的展示、点击、关闭及转化等交互数据，用于广告监测归因、广告投放统计分析和广告反作弊。性能数据：如崩溃数据、性能数据，用于减少应用崩溃并提供稳定可靠的服务。上述信息的处理方式主要为 SDK 在你同意隐私政策后通过系统 API 读取、收集、记录相关字段，或在广告请求、广告展示、点击、关闭、下载、安装、转化、落地页唤起等环节生成相关数据；处理范围以广告服务、广告监测归因、广告反作弊、广告投放统计分析、广告落地页适配和稳定性保障所必需的最小范围为限。

6. 权限申请与用途说明

结合当前 Android 版本的实际接入情况，本应用及已接入的广告 SDK 可能申请或使用以下权限：INTERNET，用于访问远程广告开关、请求广告内容与完成必要网络通信；ACCESS_NETWORK_STATE，用于判断网络状态并保障广告服务稳定性；ACCESS_WIFI_STATE，用于识别 Wi‑Fi 连接状态并优化广告请求；REQUEST_INSTALL_PACKAGES，仅在你主动点击下载类广告且需要安装应用时用于调起系统安装流程；系统媒体读写能力，仅在你主动选择照片或保存导出时用于读取你选定的照片及保存生成结果。当前安装包未主动声明 READ_PHONE_STATE、精确定位、粗略定位、QUERY_ALL_PACKAGES、POST_NOTIFICATIONS 等穿山甲可选广告权限；如后续版本新增相关权限或能力，我们会同步更新本隐私政策。

7. 数据传输与共享说明

本应用不提供账号系统、云端备份或联网图片处理能力，照片分析、颜色提取和卡片渲染均在设备本地完成。除广告服务所必需的信息外，我们不会向第三方共享、转让或公开披露你选择的原始照片、照片元数据或导出内容。与广告相关的必要信息可能由我们与北京巨量引擎网络技术有限公司及其广告合作方按照各自职责在去标识化、最小必要范围内处理；相关信息可能包括设备信息、网络信息、应用信息、软件列表信息、已安装应用列表、设备 MAC 地址、传感器列表、传感器信息、广告交互数据以及必要的崩溃和性能数据；处理目的主要为广告展示、广告请求与填充、广告落地页唤起适配、广告监测归因、广告反作弊、统计分析和稳定性保障。根据穿山甲官方公示，穿山甲广告 SDK 为实现特定功能还可能接入合作方 SDK，具体合作方范围及信息处理情况以其官方公示页面和当时实际接入版本为准。

8. 缓存、临时文件与本地保存

为完成图片读取、预览、动态照片解析、图片导出或广告素材加载，应用可能在设备缓存目录临时生成中间文件。这些缓存和临时文件仅在实现当前功能所需的合理期限内保存，不作为长期个人资料保存。你主动导出的图片结果将保存到你选择的本地存储位置或系统相册中；原始照片仍由你的系统相册或原始存储位置自行管理。

我们重视个人信息安全，并采取与本应用形态相匹配的保护措施，包括依托系统权限校验、应用沙箱、文件隔离、签名校验、最小必要访问控制以及开发维护过程中的依赖检查与安全审计，降低未经授权访问、披露、篡改或丢失的风险。

你可以拒绝授予照片访问、保存或安装相关权限；拒绝后，对应图片处理、导出保存、下载类广告或广告效果可能受到影响。你也可以在首次弹窗中选择不同意本隐私政策，不同意后应用不会继续提供需要读取照片或启动广告 SDK 的功能页面；在已同意后，你仍可通过删除应用、清理缓存、删除导出结果或在系统设置中管理相关权限，来停止后续本地保留或限制可选信息处理。如你希望进一步了解或行使与第三方广告 SDK 相关的个人信息权利，也可以依据穿山甲官方公示页面中的说明进行查询，或通过本政策中的联系方式与我们联系。
