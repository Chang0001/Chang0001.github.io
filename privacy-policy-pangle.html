PhotoColours

隐私政策

PhotoColours 是一款以本地图片处理为核心的应用，提供照片色盘提取、卡片排版、图片导出等功能。当前版本同时接入穿山甲广告 SDK， 用于广告展示与广告效果统计。本政策用于说明我们以及相关第三方如何处理你的个人信息。

更新日期：2026年4月24日
适用于：Android 版本（含穿山甲广告 SDK）

1. 开发者信息与联系方式

本应用开发者为滨州幻境网络科技有限公司。如你对本隐私政策、个人信息保护或第三方 SDK 接入情况有疑问、意见或建议，可通过以下方式联系我们：1529856440@qq.com。

2. 我们处理的本地图片信息

当你主动选择照片时，本应用会在设备本地处理与你所选照片相关的信息，包括照片像素内容、照片中可读取的拍摄时间、位置信息以及动态照片附带的本地元数据。这些处理用于完成颜色提取、背景色计算、卡片文案默认值生成、排版预览以及最终图片导出。

除你主动导出或系统正常读写所必需的处理外，我们不会因为广告展示而上传你的原始照片、照片元数据或导出后的图片内容。

3. 接入的第三方 SDK：穿山甲广告 SDK

当前版本接入了穿山甲广告 SDK，由北京巨量引擎网络技术有限公司提供，主要用于广告展示、广告请求与填充、广告监测归因、反作弊、广告效果统计分析、广告落地页唤起与稳定性保障。

按照当前版本的实现，只有在你阅读并同意本隐私政策后，应用才会启动广告相关服务。

  • 穿山甲 SDK 服务基本信息公示与隐私说明：https://www.csjplatform.com/privacy/partner
  • 穿山甲官方合规指南：https://www.csjplatform.com/terms/compliance-guide
  • 穿山甲 Android SDK 接入说明：https://www.csjplatform.com/supportcenter/5397

4. 穿山甲广告 SDK 可能处理的信息类型

根据穿山甲官方公示及其 SDK 能力说明，广告 SDK 在实际运行中可能处理以下信息：

  • 设备基础信息与标识信息：如设备品牌、设备型号、操作系统版本、屏幕参数、OAID、Android ID 等；
  • 网络信息：如 IP 地址、网络连接状态、Wi‑Fi 状态、运营商信息、网络信号相关信息；
  • 网络标识信息：如设备 MAC 地址或 Wi‑Fi 接入标识，具体以系统和设备实际可返回的信息为准；
  • 应用信息：如应用包名、版本号、前后台状态、广告位信息；
  • 软件列表相关信息：如设备已安装应用信息、应用包名列表，用于广告投放适配、广告落地页唤起、反作弊、归因分析与安全风控；
  • 广告交互数据：如广告展示、点击、关闭、转化等交互行为；
  • 必要的日志、崩溃、性能与安全风控信息。

如后续版本接入下载类广告，且你主动点击下载安装相关广告内容，还可能涉及广告下载过程、安装状态及与安装行为相关的信息处理。

5. 权限申请与用途说明

结合当前 Android 版本的实际接入情况，本应用及已接入的广告 SDK 可能申请或使用以下权限：

  • INTERNET：用于访问远程广告开关、请求广告内容与完成必要的网络通信；
  • ACCESS_NETWORK_STATE：用于判断当前网络状态，保障广告请求与服务稳定性；
  • ACCESS_WIFI_STATE：用于识别 Wi‑Fi 连接状态，优化网络环境下的广告请求或下载行为；
  • REQUEST_INSTALL_PACKAGES：仅在你主动点击下载类广告并需要安装应用时，用于调起系统安装流程；
  • 系统媒体读写能力：仅在你主动选择照片或触发保存导出时，用于读取你选定的照片以及把生成结果保存到本机相册或存储位置。

当前安装包未主动声明 READ_PHONE_STATE、精确定位、粗略定位、QUERY_ALL_PACKAGES、POST_NOTIFICATIONS 等穿山甲可选广告权限。如后续版本新增相关权限，我们会同步更新本隐私政策。

6. 数据传输与第三方共享说明

本应用不提供账号系统、云端备份或联网图片处理能力，照片分析、颜色提取和卡片渲染均在设备本地完成。除广告服务所必需的设备信息、网络信息、广告交互数据以及稳定性保障信息外，我们不会向第三方共享、转让或公开披露你选择的原始照片、照片元数据或导出内容。

与广告相关的必要信息可能由我们与北京巨量引擎网络技术有限公司及其广告合作方按照各自职责在去标识化、最小必要范围内处理。相关信息包括设备信息、网络信息、网络标识信息、软件列表相关信息、广告交互数据以及必要的安全风控信息；其处理方式主要为已接入广告 SDK 通过系统接口读取或在广告请求、展示、点击、下载、落地页唤起等环节生成；处理范围以广告服务所必需的最小范围为限，用于广告展示、唤起适配、监测归因、反作弊、频控与统计分析。

7. 缓存、临时文件与本地保存

为完成图片读取、预览、动态照片解析、图片导出或广告素材加载，应用可能在设备缓存目录临时生成中间文件。这些缓存和临时文件仅在实现当前功能所需的合理期限内保存，不作为长期个人资料保存。

你主动导出的图片结果将保存到你选择的本地存储位置或系统相册中；原始照片仍由你的系统相册或原始存储位置自行管理。

8. 我们如何保护你的信息

我们重视个人信息安全，并采取与本应用形态相匹配的保护措施，包括依托系统权限校验、应用沙箱、文件隔离、签名校验、最小必要访问控制以及开发维护过程中的依赖检查与安全审计，降低未经授权访问、披露、篡改或丢失的风险。

9. 你的选择与权利

你可以拒绝授予照片访问、保存或安装相关权限；拒绝后，对应图片处理、导出保存、下载类广告或广告效果可能受到影响。你也可以通过删除应用、清理缓存、删除导出结果或在系统设置中管理相关权限，来停止后续本地保留或限制可选信息处理。

如你希望进一步了解或行使与第三方广告 SDK 相关的个人信息权利，也可以依据穿山甲官方公示页面中的说明进行查询，或通过本政策中的联系方式与我们联系。

10. 未成年人保护

如你是未成年人，建议在监护人陪同下阅读并理解本隐私政策，并在取得监护人同意后使用相关功能。监护人如对未成年人个人信息保护有疑问，可通过本政策中的联系方式与我们联系。

11. 政策更新

若应用功能、广告合作方式、权限申请范围、第三方 SDK 接入情况或个人信息处理方式发生变化，我们会同步更新本隐私政策，并在应用内、上架资料页或相关公示页面中公布最新版本。

你继续使用 PhotoColours 的相关功能，即表示你已阅读、理解并同意本隐私政策。若你不同意本政策的全部或部分内容，你应停止使用相关功能。
